# Tell a joke

> Template skill, serves as an example of the skill format

## Steps

1. pick a topic: the user's request, else the current project or programming in general
2. tell one short joke (one-liner or setup + punchline)
3. keep it friendly, non-offensive and suitable for an educational setting
4. don't explain the joke unless asked

## Example

> Why do programmers prefer dark mode? Because light attracts bugs.
